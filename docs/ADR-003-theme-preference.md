# ADR-003: ธีมสว่างและธีมมืด

## สถานะ
ยอมรับสำหรับการทดลองใช้งาน

## บริบท
ผู้ใช้ต้องการเลือกธีมสว่างหรือธีมมืด โดยแอปควรเหมาะกับสภาพแสงและจำตัวเลือกของผู้ใช้ข้ามการเปิดใช้งาน รวมถึงรักษาสีเขียวที่เป็นเอกลักษณ์ของผลิตภัณฑ์

## การตัดสินใจ

- รองรับ Theme สองค่า ได้แก่ `light` และ `dark`
- หากยังไม่มี Theme Preference ที่ถูกต้อง ให้เริ่มจาก `prefers-color-scheme` ของระบบ
- เมื่อผู้ใช้เลือก Theme แล้ว ให้บันทึกลง `localStorage` และใช้ค่านั้นเหนือค่าของระบบในการเปิดครั้งถัดไป
- ไม่มีตัวเลือกกลับไปติดตามธีมระบบจาก UI; ค่าที่ผู้ใช้เลือกล่าสุดมีผลต่อเนื่อง
- หากค่าที่จัดเก็บไม่ใช่ `light` หรือ `dark` ให้ละทิ้งและกลับไปใช้ธีมระบบ
- ซิงก์การเปลี่ยน Theme ระหว่างแท็บทันทีผ่าน `storage` event
- ผู้ใช้ต้องเปิด Settings Surface ก่อนจึงเห็น Theme Toggle
- เดสก์ท็อปใช้ settings popover เหนือปุ่มตั้งค่า ส่วนมือถือใช้ bottom sheet จากด้านล่าง แนวทางนี้อยู่ในสถานะทดลองและปรับได้หลังทดสอบการใช้งาน
- Theme Toggle แสดงไอคอนของธีมปลายทาง: ดวงจันทร์หมายถึงเปลี่ยนเป็นมืด และดวงอาทิตย์หมายถึงเปลี่ยนเป็นสว่าง
- การเปลี่ยนสีใช้ animation สั้น และต้องไม่รบกวนผู้ใช้ที่ตั้งค่า `prefers-reduced-motion`
- ปุ่มรองรับคีย์บอร์ด มี focus state, tooltip และ accessible name ที่บอกการกระทำ
- ธีมมืดคงสีเขียวหลัก สีเขียวของ Income และสีส้มของ Expense พร้อมปรับพื้นหลัง การ์ด เส้นขอบ ข้อความ input, modal และสีกราฟให้มี contrast เหมาะสม

## ผลกระทบ

ผู้ใช้ได้ประสบการณ์ที่สอดคล้องกับระบบในครั้งแรกและคงตัวเลือกส่วนตัวหลังจากนั้น การซิงก์ข้ามแท็บทำให้หน้าต่างทั้งหมดสอดคล้องกัน แต่ Theme Preference ยังคงเป็นข้อมูลเฉพาะเบราว์เซอร์และอุปกรณ์

## จุดตรวจสอบหลังทดลองใช้

- popover และ bottom sheet ค้นพบได้ง่ายหรือไม่
- animation ทำให้รู้สึกต่อเนื่องโดยไม่ช้าหรือรบกวนหรือไม่
- สีข้อความ controls และกราฟผ่านเกณฑ์ contrast ในทั้งสองธีมหรือไม่
