# ADR-002: การลบรายการและคำนวณสถานะใหม่

## สถานะ
ยอมรับ

## บริบท
ผู้ใช้ต้องนำ Transaction ที่ไม่ต้องการออก และข้อมูลสรุปทุกส่วนต้องตรงกับรายการที่ยังเหลืออยู่

## การตัดสินใจ
แต่ละรายการมีปุ่มลบที่ระบุชื่อรายการสำหรับเทคโนโลยีช่วยการเข้าถึง การลบใช้รหัสรายการกรอง Transaction ออกจาก state ชุดเดียวที่เป็นแหล่งข้อมูลหลัก จากนั้น Balance, Income, Expense, Budget และ Category breakdown จะถูกคำนวณใหม่ และผลลัพธ์ถูกบันทึกลง `localStorage` อัตโนมัติ

## ผลกระทบ
ทุกส่วนของหน้าจอสอดคล้องกันโดยไม่ต้องแก้ยอดแยกส่วน การลบมีผลทันทีและยังไม่มี undo หรือถังขยะ
