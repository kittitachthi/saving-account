# ADR-001: หน้าหลักสำหรับจัดการเงินรายวัน

## สถานะ
ยอมรับ

## บริบท
ผู้ใช้ต้องการเห็นรายรับ รายจ่าย และเงินคงเหลือได้รวดเร็ว พร้อมบันทึกรายการโดยไม่ต้องเปลี่ยนหน้า

## การตัดสินใจ
ใช้แดชบอร์ดหน้าเดียว โดยวางยอดคงเหลือไว้เด่นที่สุด ตามด้วยรายรับ รายจ่าย งบประมาณ และรายการล่าสุด ฟอร์มเพิ่มรายการแสดงเป็น modal และคำนวณยอดใหม่ทันที

## ผลกระทบ
ใช้งานประจำวันได้เร็วและรองรับมือถือ ข้อมูลยังเป็นสถานะชั่วคราวและจะเริ่มใหม่เมื่อรีเฟรช จนกว่าจะเชื่อมฐานข้อมูลหรือ local storage
