# Dashboard mascot assets

Created with the built-in image generation tool on 2026-09-07, using the existing Pocka mascot as the edit target. Marketing retains its original image. Income intentionally reuses that original joyful coin-holding pose; the five new cutouts are separate dashboard assets.

Shared generation prompt: Create one standalone UI sprite. Preserve the recognizable green coin-purse character, pale green face patch, gold clasp, green arms/legs and soft 3D toy style. Full body centered, no scene or backdrop, transparent PNG, no extra text except Z for sleeping.

- idle: Calm closed-mouth gentle smile, relaxed standing pose, no coin in hands.
- income: Joyful delighted smile, holding gold coin, two tiny green sparkles.
- expense: Friendly reassuring gentle smile, holding a paper receipt in its hand instead of a coin. No sad or worried expression.
- saving: Celebratory delighted smile, holding a gold star, a few small gold star sparkles.
- sleeping: Clearly asleep, eyes closed, peaceful closed-mouth expression, relaxed pose, small Z above head.
- error: Mildly concerned but kind expression, small closed mouth, gently raised eyebrows, open reassuring hands. No tears, no red, no danger symbols.

Background extraction prompt used to remove generated opaque checkerboards: “Remove background. Transparent PNG with alpha channel. No checkerboard pixels. Keep only the character and its accessories.” All selected final cutouts were inspected against the dashboard background. Unselected generations remain outside the project.
